There is no student data.

Not a promise to handle it carefully — there is nothing to handle. No student signs in, no field exists to hold a student's name or email, and the join code is a room number rather than a key. Instructors do have accounts, so the database holds a username and a password hash for each one — staff records, and the whole of the personal data in this system. What is stored, and how to check.
